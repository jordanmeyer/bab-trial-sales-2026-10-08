# Decisions

- Simulated student owns domain choices; exact interview retained separately. Contribution profit rather than net profit avoids implying overhead is counted.
- Strict whole-file rejection prevents silently biased totals. Current data survives failed imports.
- Integer-cent arithmetic, input caps and safe-integer aggregate checks make displayed money exact within the accepted range.
- Date/region/product filters combine; all totals describe only visible matching records.
- All data is synthetic or visitor-selected transient local data. No services, storage, analytics or external assets.
- Built-in Georgia and Arial substitute for downloadable brand families. Unchanged Duke navy/royal are used as public design guidance; no marks or endorsement claims.
- Initial public destination authorized: jordanmeyer/bab-trial-sales-2026-10-08. Parent coordinates repository creation/push/live checks.

- After the first live deployment, the simulated student approved an active-filter summary to reduce confusion between filtered and whole-dataset totals. It changes presentation only.

- Version the changed sales entry script URL as app.js?v=2. Initially prompted by a sibling trial failure, this was then supported by actual sales live observation: returning visitors received new HTML but stale app.js and no filter summary. A successful Actions run did not establish successful update behavior.
